Guide Posture dashboard — design rules

Mark
Ring mark + Archivo "Patched" lockup, top-left of the sidebar (mark 22px). Outline ring on snow.
Hero metric
The posture bar is the hero — not a chart. Closed = slate, the closing front = one signal segment, open = faint. Score in Archivo, the one orange number.
Type & data
Archivo headings, Inter UI, JetBrains Mono for IDs, labels & tabular data. Status chips in mono.
Surface
Flat snow, 1px hairline rules, 3px radii, no shadow on cards. Active nav = 2px signal rail. One orange event per view.
