# Font licence notices

This directory retains the full licence texts for inherited Inter 4.000, Archivo 2.001, and JetBrains Mono 2.304 font assets. Inter and Archivo notices were copied from `platform/go-service/internal/report/assets/fonts`; JetBrains Mono OFL v2.304 was supplied from the official upstream release. Exact font binary origins are not fully pinned in this snapshot. Review provenance and distribution terms before any public distribution. This notice records inherited licence texts and does not provide legal clearance or grant a new licence to Patched source.
