Guide patched.im — design rules

Mark
Ring mark + Archivo "Patched" lockup, top-left. Outline ring on light chrome; never the pixel-P here.
Type
Archivo 700 display (hero 64 / H2 52–34), Inter 16.5 body, JetBrains Mono uppercase eyebrows & data.
Colour
Snow + paper surfaces, slate ink, one signal-orange event per view (≤2%).
Layout
40px margins, sections split by 1px rules (not whitespace), the posture arc / closing-line as the graphic device, buttons 4px radius.
