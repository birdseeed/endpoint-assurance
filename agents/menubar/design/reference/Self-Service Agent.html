Patched — self-service agent

Menu-bar & tray — the surface users actually open.

The agent manages third-party app updates. Click the ring mark in the menu bar / tray and this panel drops down: device posture as the gauge, the apps that need patching, and one button to patch all. All UI is in the OS system font (SF on macOS, Segoe UI on Windows) — only the “Patched” lockup is Archivo. Apps patched · patching · unpatched.

What this is. The self-service entry point on both platforms: posture as the gauge, the apps needing patching, one Patch all, and an Open Self Service → deep-link. Mark in the menu bar is the mono template (orange drops to ink). Everything here is the OS system font; the “Patched” lockup is the only Archivo.
