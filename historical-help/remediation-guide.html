Guide 09

Remediation guide

Every finding in your report already comes with a one-line fix. This is the longer version for the dozen or so CIS Level 1 controls that show up most often across real estates: what the setting is, why it's on the benchmark, and a link to the vendor's own instructions.

These are general instructions for an administrator with local access to the device. On a managed estate, push the equivalent setting through Intune or your MDM rather than visiting every machine; your report's per-device appendix tells you which devices still need it.

macOS

FileVault disk encryption

Encrypts the startup disk so its contents are unreadable without the login password or recovery key. This is the single highest-impact setting on the benchmark: a lost or stolen laptop without it is a plain data breach, with it it's a lost laptop. Enable in System Settings → Privacy & Security → FileVault. See Apple's FileVault guide.

Firewall enabled

Blocks unsolicited inbound connections to the Mac. Low friction, no effect on normal outbound use (browsing, email, the Patched agent itself). Enable in System Settings → Network → Firewall. See Apple's firewall guide.

Automatic security updates

Installs Apple's security patches (Rapid Security Responses and minor OS updates) without waiting on someone to click Update. This is usually the single biggest lever on your Patch Currency score, and it's a one-time setting, not an ongoing task. Enable in System Settings → General → Software Update → Automatic Updates. See Apple's software update guide.

Screen lock timeout

Requires a password after a short period of inactivity, so a device left unlocked in an office or on a train isn't an open door. The benchmark expects five minutes or less. Set in System Settings → Lock Screen → “Require password after screen saver begins or display is turned off”. See Apple's lock screen guide.

Gatekeeper enforcing signed software

Stops unsigned or unnotarised applications from running without an explicit override, which is most malware's easiest way onto a Mac. This should already be on by default; if it's failing, something has been changed to allow software from anywhere. Check in System Settings → Privacy & Security → Security. See Apple's Gatekeeper guide.

Guest account disabled

A guest account is passwordless access to the machine by design. Almost no SME estate needs it switched on. Disable in System Settings → Users & Groups → Guest User. See Apple's guest user guide.

Remote login (SSH) disabled

Remote Login opens an SSH server on the Mac. Unless you specifically use SSH to manage the device, it's an exposed service with no upside. Disable in System Settings → General → Sharing → Remote Login. See Apple's sharing settings guide.

Remote management / screen sharing disabled

Screen Sharing and Remote Management let another machine control this one. Fine if it's how your IT contact supports the estate; otherwise it's another exposed service worth switching off. Review in System Settings → General → Sharing. See Apple's screen sharing guide.

Bluetooth disabled when not required

The lowest-severity finding on this list, but the most common: leaving Bluetooth on when nothing needs it slightly widens the device's radio attack surface. Turn off in Control Centre or System Settings → Bluetooth when you're not using a Bluetooth peripheral. See Apple's Bluetooth guide.

Local administrator account count

Every account with admin rights is an account that, if compromised, can change anything on the device. The benchmark expects the smallest practical number of admin accounts, with everyday users on standard accounts. Review and demote in System Settings → Users & Groups. See Apple's user accounts guide.

Windows

Windows CIS Level 1 coverage is rolling out alongside the Windows agent. The controls most estates hit today:

Microsoft Defender real-time protection

Real-time protection scans files as they're accessed rather than on a schedule, catching most commodity malware before it runs. It's on by default on a clean install of Windows; if it's failing, another AV product may have disabled it without fully replacing the coverage. Check in Windows Security → Virus & threat protection. See Microsoft's Defender Antivirus guide.

BitLocker disk encryption

The Windows equivalent of FileVault: it encrypts the system drive so a lost or stolen device doesn't expose its data. Enable in Settings → Privacy & Security → Device encryption, or the full BitLocker control panel on Pro/Enterprise editions. See Microsoft's device encryption guide.

Windows Update kept current

Pending cumulative updates are how known, already-patched vulnerabilities stay open across an estate. Set to install automatically in Settings → Windows Update → Advanced options. See Microsoft's Windows Update guide.
