Guide 02

The endpoint agent

The Patched agent is a collector. It observes device, software and configuration evidence, queues it safely and sends it to Patched. It does not replace your endpoint-management platform.

The agent: what it collects

The agent takes a periodic read-only snapshot of each device. It does not install software, change settings, or touch user data. It collects:

GroupExamples
Hardware identitySerial, hardware UUID, model, architecture, hostname
Specs & healthCPU, RAM, disk space, battery condition, SMART status
Operating systemOS version and build, last boot, pending updates
SoftwareInstalled applications, discovered names, versions and available identity evidence
CIS security signalsFileVault, firewall, Gatekeeper, SIP, screen-lock, remote access, password policy, admin count, and more
CertificatesSystem-keychain certificate inventory with expiry tracking

On macOS these come from standard Apple tools (ioreg, fdesetup, spctl, softwareupdate, and similar); on Windows from the equivalent built-in queries. Everything collected maps to a reporting or compliance purpose. There's no general-purpose surveillance, no keystroke or screen capture, no browsing history.

How the agent runs

On each run the agent writes a snapshot to a local queue, then a background uploader delivers it to api.patched.im. Two properties matter:

  • Authenticated & signed. Every upload carries your tenant's bearer token and an HMAC-SHA256 signature over the exact bytes of the payload. The server verifies both before reading a single field, plus a timestamp and a one-time nonce to defeat replay.
  • Resilient. If a device is offline or the network blips, snapshots stay queued and retry automatically (for up to 7 days). You don't lose a day's posture because a laptop was on a plane.

Uploads run about every 15 minutes. Nothing on the device listens for inbound connections; the agent only ever reaches out.

Raw data is the source of truth. We archive each device snapshot immutably and derive your dashboard and reports from it. That means a new or revised compliance rule can be re-applied to history ("what would today's benchmark say about last quarter?") without re-collecting anything.

What the agent is not asked to do

Patched findings are remediated through Intune, Jamf, a specialist patch-management product or a ticketing workflow. Patched does not require the collector to host installers, maintain package scripts or provide a Self Service application store.

Legacy deployment code may still be present while it is isolated. Its presence is not a supported product promise. The retained contract is evidence collection and authenticated upload.

Platforms

The agent supports macOS and Windows. Platform collectors use different operating-system sources but send a common, versioned inventory payload. Results are normalised server-side so governance and assurance concepts stay platform-neutral.

Privacy & control

Compliance signals that could touch user-specific data are flagged and gated. We don't switch on a control that reads personal data without a documented reason and your agreement. For the full data-handling picture, see the FAQ.
