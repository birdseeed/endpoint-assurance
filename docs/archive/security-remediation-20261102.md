## Findings and candidate changes

1. **Dashboard empty operators.** When the operator list is empty, the dashboard now treats the actor as a consultant while retaining explicit-owner rules and existing Bearer administration behaviour. Focused checks passed (121 tests), and the parent rerun of the new security and Access checks passed (72 tests). The wider run reported 3,126 passed, 6 skipped and 3 failures in PAT989 long-temporary-path cases. The same three failures reproduce on baseline HEAD in a long path, while all 47 tests in the ordinary temporary-path control passed.
2. **Backup credential channel and cleanup (organisation archive only).** The reviewed finding and source repair concern a backup helper excluded by this personal copy’s existing privacy curation. No backup script or selector-liveness module has been restored here. The organisation-archive evidence does not describe retained code in this copy.
3. **Endpoint enrolment payload transport.** The endpoint enrolment path now sends the private payload through curl standard input rather than exposing it as a process argument. Parent synthetic checks passed for successful 200 responses with credentials, mode 0600, retired-token handling, and malformed 200 responses that trigger suspension. The final shell rerun passed. The first independent Astra review required changes after finding a reinstall race: a poller could consume and delete the canonical token before child preflight. The repair accepts only an absent token with all four validated private canonical credentials present; unsafe, token-empty or incomplete state is still refused, and consumed tokens are not replayed. Synthetic checks reproduced the issue before the repair and passed afterwards. A full reviewed, stubbed disposable bundle fixture passed 31 checks with no failures; native installation was not performed. Final independent static review passed after the repair; the immutable review record remains separate.
4. **Provisioning source precedence.** The canonical provisioned non-secret flag now takes precedence over stale JSON state. Parent reruns of synthetic stdin/argument, mode and failure-guard checks passed.
5. **PDF rendering resource bounds.** Text is bounded to 32 KiB per value, aggregate text to 8 MiB, logical lines to 2,048 per value and pages to 512. Layout work is bounded to 500,000 lines and two renderers, with context-aware cancellation. Limit failures return no partial PDF; budget exhaustion returns 400 and a busy renderer returns 503. Parent reruns of the targeted PDF checks originally passed (26 top-level and 55 subchecks) on Go 1.27.1. A later exact-toolchain follow-up verified the official Go 1.27.2 archive and passed the same bounded PDF pattern (26 top-level and 55 subchecks), offline module verification and `go build ./...`; see [verification follow-up](verification-20261102.md). This remains bounded source verification, not native or release validation.

These notes describe intended candidate behaviour and the evidence reported so far. They do not establish that every changed path has passed its final gate or that the candidate patch is free of regressions.
