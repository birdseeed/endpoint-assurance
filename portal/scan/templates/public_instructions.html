Export guide

How to export your Intune data

Two simple exports. Takes about 2 minutes each.

Export 1: Device inventory

Intune Admin Centre → Devices → Export

1
Open a browser and go to Microsoft Intune Admin Centre (intune.microsoft.com). Sign in with your work account.
2
In the left-hand menu, click Devices, then click All devices.
3
Near the top of the device list, click the Export button (it looks like a downward arrow). A file called something like Devices_<date>.csv will download.
4
That's it. Upload this file on the report page. It covers device names, operating systems, compliance state, and last check-in dates.
Export 2: Discovered applications

Apps → Monitor → Discovered apps → Export

1
In the Intune Admin Centre left-hand menu, click Apps.
2
Under Monitor, click Discovered apps. (If you don't see Monitor, look for it under Apps → Monitor in the sub-menu.)
3
On the Discovered apps page, click the Export button at the top. A file called something like DiscoveredApps_<date>.csv will download.
4
Upload this file on the report page. It contains the names and versions of all software detected across your enrolled devices.

Which one should I send?

Devices Use the Devices export if you want to see which devices are running out-of-date operating systems, which are non-compliant, and which haven't checked in recently. Good for an estate health-check.
Apps Use the Discovered apps export if you want to see which installed applications have known security vulnerabilities (CVEs). Good for a software risk assessment.
You can upload both. They produce separate reports.

What your report will show

  • Devices report: How many devices are on the latest OS version, how many are compliant, ownership breakdown, and a list of devices that haven't checked in for more than two weeks.
  • Applications report: Which installed apps have known CVEs (matched against the NIST National Vulnerability Database), the severity of each vulnerability, and how many apps Patched.im could patch automatically.
