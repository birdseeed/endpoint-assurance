What we collect

Patched collects presence, version and configuration shape only, never prompts, chat history, model output, file contents, keys, MCP arguments or environment values.

MCP evidence is reduced on the device to the server name, transport, executable or package, and host before it is sent. Local-model evidence contains model names and sizes only.

No known vulnerability findings appears only when every advertised current version has exactly one completed assessment. Pending, Not assessed and incomplete coverage are not clean results. A finding is not labelled as a CVE unless its authoritative advisory record supplies a CVE alias. Approval changes are audited and feed the software governance and drift reports. They do not remove, block or uninstall tooling.
