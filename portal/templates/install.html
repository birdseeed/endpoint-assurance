Deploying with an estate enrolment key

Use the key in place of <your-key> below. Never paste a real key into a script that gets logged, committed or cached - these examples use a placeholder on purpose.

Windows

Install command, for an Intune Win32 app or an RMM's install command field:

msiexec /qn /i PatchedAgent-<version>.msi ENROLLMENT_TOKEN="<your-key>"

Intune Win32 app: package the MSI with the Win32 Content Prep Tool, add it as a Win32 app, and set the command above as its install command. Use a file-based detection rule (the installed agent binary) so Intune reports success correctly.

macOS

Before running the installer, write the key to /etc/patched/enrollment-token as root - this is what the agent reads on enrolment:

sudo mkdir -p /etc/patched
sudo chmod 700 /etc/patched
sudo bash -c 'printf "%s" "<your-key>" > /etc/patched/enrollment-token'
sudo chmod 600 /etc/patched/enrollment-token
sudo chown root:wheel /etc/patched/enrollment-token

Run this as a Jamf Pro policy script, an Intune shell script, or an RMM script step, before the installer runs. Some MDMs prefer dropping a file instead of running a script: place a file named enrollment.json containing {"enrollment_token": "<your-key>"} next to the installer and it is picked up automatically.
